## 三分钟上手

1. 打开 `01_人物蒸馏主提示词_照抄版.md`，复制两条 `===` 之间的内容
2. 把【】填成你的任务（填不出写"未提供"）
3. 整段发给 AI
4. AI 会先回"理解 + 歧义清单 + 验收草案 + S1 计划"，你确认后开工
5. 交付前跑 `distill_gate.py` 一键验收（四个硬阻断全绿才算完成，旁路告警需人复核）

**嫌流程重？** 先看 `06_场景模板包.md`——小任务用 L1，填 3 行。

## 八步流程

```
1. 拿全量语料        → 章节级 txt，一章一文件
2. 台词归属          → 说话人锚定 A/B/C 级 + 对照组反推污染率
3. 锁统计口径        → 权威口径 JSON，所有数字的唯一来源
4. 挖掘语言指纹      → 句式/标点/自称/粗口/口头禅/思维模型
5. 深度蒸馏写作      → §0–§14 骨架
6. 证据表 + 人格数据 → 每条要点可回溯章号
7. 机器自检          → 硬阻断四道 + 旁路六道（distill_gate 一键）
8. 对标超越（可选）  → 拿参考件逐节比
```

## 七条铁律

| # | 铁律 | 为什么 |
|---|---|---|
| 1 | 统计分母 = 主角台词集，不是全书文本 | 全书统计差 **19 倍** |
| 2 | 台词归属分 A/B/C 级 + 设对照组 | 无对照组无法量化污染率 |
| 3 | 数字必须锁一个口径 | 口径不统一 → 误判"文档造假" |
| 4 | 每条结论标【直引】/【统计】/【推断】 | 证据分级是零编造唯一可验收方式 |
| 5 | 模型学示例 > 学规则，示例违规 = 规则作废 | 示例里的台词本身必须合规 |
| 6 | 自检器要做反向验证 | 否则是假绿 |
| 7 | system prompt 里每一处引号都要能溯源 | 全文引号都是模型可能学的东西 |

## v2.2 升级了什么（2026-10-26，S7 grounding 层 · 第5校验器）

- **新增 `groundguard_check.py`（S7 grounding 层）**：对标 GitHub 的 `pulkitj/groundguard`，补现有四校验器都漏掉的两格——
  - **非引号事实断言的 grounding**：§0/1/2/3/7/12/13 里每条陈述拿去和语料做支撑度匹配，抓"无语料支持的编造断言"（scan_fabrication 只验引号、semantic_check 需调模型）。
  - **数字量级矛盾**：抽事实章节数字+单位，和语料对照，抓"同单位比值>3倍"的量级冲突与"语料完全找不到"的孤立数字。
- **零成本优先（呼应省积分铁律）**：默认离线 BM25 层（字符 bigram overlap coefficient，纯标准库、不联网、不烧积分）；检测到 `groundguard` 包已安装时，`--backend groundguard` 自动升级到 LLM 层。
- 内置 `--selftest` 反向验证（铁律 6）：用文档里秦风 p300 反转案例做素材，断言能抓出"数字量级矛盾 + 非引号事实断言无支撑"，且误伤有语料支持的断言。
- 选型与调研见桌面 `蒸馏工作流_GitHub优化调研.md`（本轮 GitHub 对标成果）。

## v2.3 升级了什么（2026-10-26，S2/S4/S6 离线模板三连 · 对标 GitHub 补齐最后 3 个离线优化点）

## v2.4 升级了什么（2026-10-26，统一质量门 + OOC 漂移 + 离线语义预筛）

本轮在 v2.3「4 个离线点 100% 落地」基础上继续榨干离线可做的部分，新增 3 套纯标准库模板（均 `--selftest` PASS、零成本不烧积分）：

- **新增 `distill_gate.py`（S7 · 统一质量门）**：把分散的 5 校验器 + S2/S4/S6 模板 + 2 套离线增强**一键串起来**，按七条铁律汇总成单一 PASS/FAIL + 风险清单。分类逻辑：
  - **硬阻断（失败→整体 FAIL）**：selfcheck / scan_fabrication / verify_citations / evidence_linter——漏了就是"零编造"破防。
  - **旁路（失败→仅告警不阻断）**：semantic_check / groundguard_check / speech_crosscheck / style_fingerprint / nli_lite / character_drift——报线索不判决，需人工复核。
  - 改完文档一键验收：`python distill_gate.py`，报告落 `DISTILL_STATS/gate_report.json`。
- **新增 `character_drift.py`（S2/S7 · 对标 dsh-character-profiler）**：补「动态一致」维度——**出场权重统计**（章节分布/对话段数）+ **人设漂移监控**（人设关键词前高后崩即告警）。铁律管"静态正确"，它管"前期冷酷后期突然圣母"这类 OOC。
- **新增 `nli_lite.py`（S7 · 对标 selfcheckgpt NLI 的离线版）**：纯词典「反义对立 / 否定翻转」矛盾检测，给 `semantic_check` 当**离线预筛**——不调模型就先抓一批明确极性反转的断言，把要烧积分的 LLM 调用压到最小（省积分铁律）。命中属"待复核线索"，非判决。

> 至此离线能做的点基本榨干：GitHub 调研 8 个优化点中，#1/#2/#3/#4 已落（v2.2/v2.3），#8 OOC 漂移、#5 的离线语义预筛已落（v2.4）；剩 #5 的 NLI 模型后端 / #6 S1 抓书 / #7 S8 自动评测 仍依赖网络/API/本地模型/真实语料，需回真实环境。
